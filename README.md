# Vocabulary Trainer

Консольное приложение для изучения иностранных слов.

Программа позволяет создавать и редактировать собственный словарь, тренироваться в запоминании слов и отслеживать результаты обучения. Для каждого слова сохраняется статистика, на основе которой определяется его текущий статус и планируется следующее повторение.

## Возможности

### Работа со словарём

Приложение позволяет:

* добавлять новые слова;
* редактировать существующие слова;
* удалять слова;
* искать слова в словаре;
* просматривать содержимое словаря;
* хранить перевод, пример употребления и категорию слова.

### Тренировка

В режиме тренировки программа:

* выбирает слова для повторения;
* предлагает пользователю вспомнить перевод;
* проверяет ответ;
* учитывает правильные и неправильные ответы;
* сохраняет результаты тренировки;
* отслеживает серию правильных ответов;
* изменяет статус слова в зависимости от результатов обучения;
* рассчитывает время следующего повторения.

Таким образом, слова не просто случайно показываются пользователю, а постепенно переходят между состояниями обучения в зависимости от результатов.

### Статистика

Для каждого слова сохраняется статистика:

* количество показов;
* количество правильных ответов;
* серия правильных ответов;
* текущий статус;
* интервал до следующего повторения;
* количество ошибок допоследнего изменения статуса
* дата следующего показа.

## Структура проекта

Проект разделён на несколько модулей, каждый из которых отвечает за свою часть программы:

* `main.py` — запуск приложения и подготовка к работе
* `menu.py` — создание и обработка меню;
* `dictionary.py` — операции со словарём;
* `trainer.py` — логика тренировок и выбора слов;
* `statistic.py` — работа со статистикой 
* `storage.py` — загрузка и сохранение данных;
* `display.py` — вывод информации и таблиц в консоль;
* `utils.py` — вспомогательные функции;
* `config.py` — константы и настройки проекта.

Данные приложения хранятся в JSON-файлах.

## Требования

Для запуска проекта необходим:

* Python 3.10 или выше.

Дополнительные сторонние библиотеки не требуются.

## Запуск

### Запуск из Visual Studio Code

1. Открыть папку проекта в Visual Studio Code.
2. Открыть файл `main.py`.
3. Запустить программу кнопкой запуска Python или через встроенный терминал командой:

```text
python main.py
```

### Запуск из Проводника Windows

Для запуска программы можно открыть папку проекта в Проводнике Windows и запустить файл `main.py`.

При наличии настроенной ассоциации файлов `.py` с Python программа запустится автоматически.

## Работа с данными

Словарь и статистика пользователя сохраняются в отдельных JSON-файлах.

Эти файлы создаются и изменяются программой автоматически. Поэтому для обычной работы с приложением редактировать их вручную не требуется.

При использовании Git файлы с пользовательскими данными не включаются в репозиторий, чтобы содержимое словаря и статистика не сохранялись вместе с исходным кодом проекта.

## Как пользоваться приложением

После запуска открывается главное меню.

Сначала можно добавить слова в словарь, указав необходимые сведения о слове. После этого слова становятся доступными для тренировок.

Во время тренировки программа показывает слово и предлагает пользователю ввести перевод. Результат ответа сохраняется в статистике.

По мере обучения статус слова изменяется. Хорошие результаты позволяют перейти к следующему этапу обучения и увеличить интервал между повторениями. Ошибки, наоборот, влияют на дальнейшее повторение слова.

После завершения тренировки пользователь может просмотреть статистику текущей сессии.
